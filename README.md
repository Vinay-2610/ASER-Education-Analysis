# 📊 ASER Education Analysis (Power BI Project)

## 🎯 Overview
This project analyzes ASER (Annual Status of Education Report) data to study learning trends across India.

## 📁 Dataset
- Years: 2014, 2016, 2018, 2022, 2024
- Variables: State, Grade, Skill, Percentage

## 🛠 Tools Used
- Excel (Data Cleaning)
- Power BI (Dashboard & Visualization)

## 📊 Key Insights
- Significant learning drop in 2022 due to COVID
- Partial recovery observed in 2024
- Math performance is consistently lower than reading
- Early grades (Grade 3) are most affected

## 📈 Dashboard Features
- Pre vs Post COVID trend analysis
- State-wise performance comparison
- Grade-wise performance insights
- KPI indicators (Average Reading, Math, Best/Worst State)

## 🚀 Problem Statement
There is no real-time system to track foundational learning gaps, leading to long-term educational issues.

## 💡 Proposed Solution
A data-driven platform that continuously tracks student performance and provides early intervention using AI.
